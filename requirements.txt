streamlit==1.54.0

🔎 Why Only Streamlit?

Because:

json, random, string, pathlib → are built-in Python libraries

Streamlit automatically installs its required dependencies (pandas, numpy, etc.)

So you don’t need to list everything manually.

💎 Professional Version (Better Practice)

If you want it cleaner (without version locking):

streamlit


This installs the latest compatible version.

🧠 How to Auto-Generate Requirements (Professional Way)

If you ever want to generate automatically:

pip freeze > requirements.txt


⚠️ But this will include many unnecessary packages.
For portfolio projects, it’s better to manually keep it clean.
